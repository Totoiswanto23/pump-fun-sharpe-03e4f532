A paper-trading launch sniper for the pump.fun replay, tuned for hourly Sharpe ratio instead of raw PnL: small stakes per coin, fast exits, tiny drawdown, and guardrail probes that keep the 20-coin bar inside a 6-hour window. It buys a fresh launch once, only if a rug filter passes, and gets out within a few slots — steady, controlled gains beat one lucky moonshot.

## Run it

```sh
node main.ts
```
